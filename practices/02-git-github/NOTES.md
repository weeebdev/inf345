# Practice 2 Notes

## What I learned about Git today

Today I learned that `git add` only stages changes — it doesn't save them permanently. The actual snapshot is created by `git commit`, which is why you can add files, review them with `git status`, and still change your mind before committing.

## A command I want to remember

`git diff --staged` — I'd use this right before committing, to double-check exactly what changes are about to go into the commit.
