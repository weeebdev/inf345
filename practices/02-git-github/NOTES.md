# Practice 2 Notes

## What I learned about Git today
Git separates the working directory, the staging area, and the repository - `git add` only marks what goes into the next commit, which is why you can split a messy set of edits into several clean, reviewable commits instead of one dump.

## A command I want to remember
`git log --oneline` - a compact view of the commit history, useful for checking my commits actually landed as separate, well-named snapshots before I push.
